# Jeziel's Portfolio Website
### Built and maintained by Jeziel Banos Gonzalez


### Project Description:

Repo contains the source code for a portfolio web page displaying the following information:

* Introduction
* Projects
* Skill Set
* Contact Information & Form

The webpage is hosted on github pages: [Portfolio Link](https://jeziel-bg.github.io/PortfolioV2/)

I regularly update the webpage to include new finished projects. 

### Implementation Details:

The web page is built using the React framework. The page is divided into 4 React components; Introduction, Projects, Skills, Contact.
Each component has its own css file to allow for easy style alteration without altering any of the other components.
